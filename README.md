## 🚀 Featured Projects

### [TracSend](https://www.tracsend.com) — Email Campaign & Tracking System
> Node.js · Express · PostgreSQL · React (TypeScript) · Tailwind CSS

Built the entire product end-to-end — from the React frontend to the Node.js API and PostgreSQL database. The core challenge was handling high-volume event data (email opens, clicks, engagement) without slowing down the main application. Solved this by implementing asynchronous event processing workflows that handle tracking in the background, keeping the user-facing app fast and responsive. Designed the PostgreSQL schema specifically for write-heavy operations and analytics queries, and built APIs covering the full campaign lifecycle: creation, scheduling, delivery, and reporting.
